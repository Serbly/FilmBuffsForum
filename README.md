# 🎬 FilmBuffs Forum

Полноценное веб-приложение — форум для обсуждения фильмов с системой аутентификации, ролями пользователей, административной панелью и кэшированием.

## 🚀 Стек технологий

- Java 17
- Spring Boot
- Spring Security
- Spring Data JPA (Hibernate)
- PostgreSQL
- Redis
- Thymeleaf
- Maven

## 📌 Функционал

### Пользовательская часть:
- Регистрация и авторизация пользователей
- Система ролей: USER / ADMIN
- Создание, редактирование и удаление постов
- Комментирование публикаций
- Поиск и фильтрация тем
- Личный профиль пользователя

### Административная часть:
- Управление пользователями
- Модерация контента
- Управление ролями
- Просмотр статистики

### Backend:
- REST API
- JWT / Session-based authentication
- Кэширование часто используемых данных через Redis
- Валидация данных
- Глобальная обработка ошибок

## 🏗 Архитектура

Проект реализован по классической многоуровневой архитектуре:

Controller → Service → Repository

Используются:
- DTO
- MapStruct / ручное маппирование
- Middleware-фильтры безопасности
- Role-based access control (RBAC)

## 🗄 База данных

PostgreSQL:

Основные таблицы:
- users
- roles
- posts
- comments
- movies

Redis используется для:
- хранения токенов

## ⚙️ Запуск проекта

1. Клонировать репозиторий:
git clone https://github.com/Serbly/FilmBuffsForum.git
2. Настроить application.yml
3. Запустить PostgreSQL и Redis
4. Запуск:
mvn spring-boot:run
